# Testing Subagent — Per-Scope Memory Index

- [Stencil test invocation vs jest direct](stencil-test-invocation-vs-jest-direct.md) — Use `pnpm --filter <pkg> run test -- <path>`, never `pnpm exec jest` or `--testPathPattern` (mangled into a char-class regex by Stencil's CLI); scope coverage with `--collectCoverageFrom`
- [No import type in spec files](stencil-spec-no-import-type.md) — Use `import { X }` not `import type { X }` in `.spec.ts` — Stencil's Babel transform does not support the standalone import type syntax
- [mock-doc MouseEvent relatedTarget](stencil-mock-doc-mouseevent-relatedtarget.md) — pass `relatedTarget` directly in the event init dict (no `Object.defineProperty` needed); `Node.contains(self)` is `true`, making `x.contains(t) || x === t` guards partly dead code
- [Registered child prop drives real lifecycle](stencil-registered-child-prop-lifecycle.md) — a JSX prop passed to a registered child custom element in `newSpecPage` reaches that child's real `componentDidLoad` logic, not just a JS property; verified via `bds-search-bar` delegating its spinner to `bds-select`
- [Verify touched lines, not whole-file %, for scoped regression checks](coverage-verify-touched-lines-not-whole-file.md) — `bds-search-bar`/`bds-select` sit at ~70-72% overall (pre-existing, unrelated debounce/keyboard code); cross-check `coverage/lcov.info` DA hit-counts for the diff's actual line range instead of blocking on the aggregate score
- [Non-shadow slot relocation before componentDidLoad](stencil-non-shadow-slot-relocation-before-componentdidload.md) — `hasSlotContent(this.el)`-style direct-childNodes checks always read false in `componentDidLoad`/`slotchange` handlers for non-shadow components; fixed in `bds-button` via upgrade-only merge (componentDidLoad) + rendered-wrapper check (slotchange) — includes the working `newSpecPage` pattern for simulating post-load slot updates
