# Testing Subagent — Per-Scope Memory Index

- [New opt-in prop breaks sibling tests in same file](stencil-new-optin-prop-breaks-sibling-tests-same-file.md) — always run the whole spec file, not just new `it`s, when implementation added a new default-false prop gating previously-unconditional markup
- [Auto-merged spec can silently regress](stencil-auto-merged-spec-silent-regression.md) — no conflict markers ≠ correct; git can silently drop one side's rewritten `it()` block or leave stale selectors from a one-sided addition; verified on `bds-table.toolbar.spec.ts` during EOA-15507 merge
- [Stencil test invocation vs jest direct](stencil-test-invocation-vs-jest-direct.md) — Use `pnpm --filter <pkg> run test -- <path>`, never `pnpm exec jest` or `--testPathPattern` (mangled into a char-class regex by Stencil's CLI); scope coverage with `--collectCoverageFrom`
- [No import type in spec files](stencil-spec-no-import-type.md) — Use `import { X }` not `import type { X }` in `.spec.ts` — Stencil's Babel transform does not support the standalone import type syntax
- [mock-doc MouseEvent relatedTarget](stencil-mock-doc-mouseevent-relatedtarget.md) — pass `relatedTarget` directly in the event init dict (no `Object.defineProperty` needed); `Node.contains(self)` is `true`, making `x.contains(t) || x === t` guards partly dead code
- [Registered child prop drives real lifecycle](stencil-registered-child-prop-lifecycle.md) — a JSX prop passed to a registered child custom element in `newSpecPage` reaches that child's real `componentDidLoad` logic, not just a JS property; verified via `bds-search-bar` delegating its spinner to `bds-select`
- [Verify touched lines, not whole-file %, for scoped regression checks](coverage-verify-touched-lines-not-whole-file.md) — `bds-search-bar`/`bds-select` sit at ~70-72% overall (pre-existing, unrelated debounce/keyboard code); cross-check `coverage/lcov.info` DA hit-counts for the diff's actual line range instead of blocking on the aggregate score
- [Non-shadow slot relocation before componentDidLoad](stencil-non-shadow-slot-relocation-before-componentdidload.md) — `hasSlotContent(this.el)`-style direct-childNodes checks always read false in `componentDidLoad`/`slotchange` handlers for non-shadow components; fixed in `bds-button` via upgrade-only merge (componentDidLoad) + rendered-wrapper check (slotchange) — includes the working `newSpecPage` pattern for simulating post-load slot updates
- [No SCSS assertion pattern exists](stencil-no-scss-assertion-pattern.md) — `newSpecPage` never loads/evaluates stylesheets (no CSSOM, no `matchMedia`); CSS-only criteria (reduced-motion, animations) can't be Jest-asserted — assert the DOM classes the CSS targets instead and note the gap explicitly; candidate for `.agents/memory/` promotion
- [bds-pagination needs setupResizeObserverMock](stencil-bds-pagination-requires-resizeobserver-mock.md) — registering `BdsPagination` as a real child in `newSpecPage` throws `ResizeObserver is not defined` unless `setupResizeObserverMock()` is also called at describe level
- [Render-spy stability, not exact count, for mutable-prop write-back loops](stencil-render-spy-stability-not-exact-count.md) — a Prop write-back + its own `@Watch` handler yields 2 `render()` calls per interaction in `newSpecPage` (harness scheduling artifact, not a bug); assert the count is stable across two distinct interactions, not `toHaveBeenCalledTimes(1)`
- [Console leak: isolate the file before trusting Jest's output order](stencil-console-leak-jest-output-order-misleading.md) — a `● Console` block's position in scoped multi-file output doesn't reliably identify the source file; isolate with an exact single-file positional path (no flags before it) to confirm before editing; `bds-button-slots.spec.ts` was the real source, not the adjacent `a11y.spec.ts`
- [@tanstack/virtual-core in mock-doc](stencil-tanstack-virtual-core-mock-doc-pattern.md) — patch `HTMLElement.prototype.offsetHeight`/`offsetWidth`/`getBoundingClientRect` (not `setupResizeObserverMock`, a no-op for this library); candidate for `.agents/memory/` promotion
- [Freeze deferred microtask via prototype spy](stencil-freeze-deferred-microtask-via-prototype-spy.md) — `await newSpecPage()` already flushes a `Promise.resolve().then()` deferred from `componentDidLoad`; `jest.spyOn(Class.prototype, 'privateInit').mockImplementation(() => {})` freezes the pre-init branch deterministically instead of racing timing; candidate for `.agents/memory/` promotion
- [ResizeObserver callback capture + bds-table conditional data-col-key](stencil-resizeobserver-callback-capture-and-conditional-data-col-key.md) — read `(global.ResizeObserver as unknown as jest.Mock).mock.calls.at(-1)?.[0]` to manually invoke a mocked ResizeObserver's callback (established in `bds-pagination`); `bds-table`'s `<th>` only carries `data-col-key` once sortable/pinned — locate by order or label text before that
- [document global works in plain (no newSpecPage) spec files](stencil-plain-spec-document-global-available.md) — `document.createElement(...)` is usable directly as a `Node` fixture in a `.spec.ts` file that never calls `newSpecPage`; confirmed on `CellContentCache` tests in `bds-table.utils.spec.ts` (EOA-16000 Task 1)
- [bds-table "row recycling" test meaning](stencil-bds-table-recycling-test-meaning.md) — `<tr>` is keyed by rowId, so cache-identity-guard tests (formatter/row-detail/template) must reassign data to new objects with the *same* ids, not simulate index-based DOM shuffling; EOA-16000 Task 3
- [bds-table items-per-page attribute bypasses pagination normalization](bds-table-getEffectiveItemsPerPage-bypasses-pagination-normalization.md) — `getEffectiveItemsPerPage` reads the raw HTML attribute unvalidated; pick a value from bds-pagination's allowed options `[10,25,50,100]` in test fixtures unless targeting this bypass itself
- [No native MutationObserver — build a functional double, filter by target](stencil-no-native-mutationobserver-functional-double-needed.md) — Stencil's spec-test env has no real MutationObserver/ResizeObserver at all; `setupMutationObserverMock()` is a permanent no-op that never fires — testing a real retry callback needs its own recording double, filtered by target since e.g. `bds-table`'s `_columnObserver` shares the same global ctor; candidate for `.agents/memory/` promotion
- [Column prop mutation doesn't re-render bds-table](bds-table-column-prop-mutation-no-rerender.md) — setting a mounted `bds-table-column`'s JS prop (e.g. `width`) post-mount does not trigger a `bds-table` re-render in `newSpecPage`; set such props via the initial `html` attribute string instead
- [bds-table rows-mode testing patterns](bds-table-rows-mode-testing.md) — re-emitted `bdsPageChange` double-count fix (dispatch with `bubbles: false`), Stencil dev-mode `componentDidLoad` state-write warning noise, empty-state row count gotcha, `bds-pagination`'s readonly `currentPage` is writable at runtime
- [No DragEvent/DataTransfer in mock-doc](stencil-mock-doc-no-dragevent-datatransfer.md) — `newSpecPage` has no global `DragEvent`/`DataTransfer`; use the shared `createDragDataTransferMock`/`createDragEvent` helper from `src/utils/testing/mocks/dragDrop.ts` (resolves via `@/utils`) instead of hand-rolling it per spec file — promoted to `.agents/memory/`
- [bds-table column reorder invariant](bds-table-reorder-boundary-pinned-invariant.md) — a boundary-pinned column (first/last in `columnOrder`) keeps its physical DOM index under any Task-5 reorder since pinned columns are always excluded as drag source/target; pin-offset regression tests can safely use boundary-pinned fixtures without hitting VDOM non-keyed `<th>` reuse edge cases
- [bds-table resize throttle spy target](bds-table-resize-throttle-spy-target.md) — `componentDidRender` calls `updatePinnedColumnOffsets()` unforced every render; spy on the `th[data-pinned]` querySelectorAll count, not raw method-call count, to assert throttling
- [mock-doc has no capture-phase ordering](stencil-mock-doc-no-capture-phase-ordering.md) — dispatching `click` directly on a child fires the child's own listener before an ancestor's `{capture:true}` listener; dispatch on a plain ancestor node instead so `.closest()` still matches; candidate for `.agents/memory/` promotion
- [bds-checkbox Host onClick causes double-toggle](stencil-bds-checkbox-host-onclick-double-toggle.md) — `bds-checkbox` emits its own real `bdsChange` from a dispatched `click` (Host has `onClick`); don't also manually dispatch `bdsChange` on the same interaction or selection cancels itself back out; found via `bds-table` `rowClickSelects` (EOA-16000 Task 12); candidate for `.agents/memory/` promotion
- [jest.useFakeTimers() hangs newSpecPage instead of failing fast](stencil-fake-timers-hang-newspecpage-async.md) — never let fake timers span an `await newSpecPage`/`waitForChanges` call; scope freeze/restore tightly around the synchronous fixture-building call only; candidate for `.agents/memory/` promotion
- [getComputedStyle custom property overrides are unmockable in newSpecPage](stencil-getcomputedstyle-custom-property-unmockable.md) — `global.getComputedStyle` is pre-bound to `MockWindow.prototype.getComputedStyle` before any test runs and is a different reference from `window.getComputedStyle`, so `jest.spyOn(window, 'getComputedStyle')` never intercepts a component's bare call; mock-doc's own stub also ignores the element and always returns `''`; only assert the TS-constant-fallback path, route CSS-override verification to Storybook/manual testing; found via `bds-table` `getMinColumnWidth`
- [Stencil boolean ARIA attrs serialize as "" / omitted, not "true"/"false"](stencil-boolean-aria-attr-serialization.md) — `aria-selected={boolean}` renders `aria-selected=""` when true and no attribute at all when false (same code path as `disabled`); assert with `hasAttribute`, not `getAttribute(...).toBe('true')`; string-valued conditional attrs (`aria-current={cond ? 'date' : undefined}`) are unaffected; found via `bds-calendar-grid` a11y spec, EOA-16692 Task 11
- [Commit scope is the package, not the component](../../../.agents/memory/commitlint-scope-is-package-not-component.md) — promoted to team memory; commitlint's `scope-enum` only allows `[react, vue, web-components, styles, docs, examples, scripts, workspace, ci, deps, release, multiple]`; use `test(web-components): ...`, never `test(bds-calendar-grid): ...` even if a task's stated commit message uses the component name — check prior commits in the branch (`git log --oneline`) for the actual convention before committing
