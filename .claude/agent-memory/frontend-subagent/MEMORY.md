- [Re-audit JSDoc on every API change](feedback_jsdoc_sync_on_change.md) — `@slot` tags drift silently because CEM can't infer them from render(); verify class JSDoc against render() before finishing any component edit (bds-table `search-bar` incident, EOA-14935)

- [PREFIX constant](feedback_prefix_constant.md) — declare `const PREFIX = 'bds-tag' as const` at the top of every component; use in all class template literals

- [SCSS BEM nesting](feedback_scss_bem_nesting.md) — nest all `&__element` rules inside the block selector; never write flat `.bds-component__element` selectors
- [Component code organization](component-code-organization-bds-table.md) — `@Element()` before `@State()`; lifecycle section 9 follows execution order (`componentDidRender` before `componentDidLoad`); section comments omitted by team preference; `@State()` JSDoc is optional
- [Collapsed-trigger focus/scroll bug pattern](feedback_scroll_into_view_collapsed_focusable.md) — manage tabindex on every internal focusable, not just the visible trigger, or reverse Tab can bypass the expand handler and corrupt scrollLeft on overflow:hidden containers
- [bds-search-bar scroll-clip fix (EOA-15204)](stencil-search-bar-scroll-clip-bug.md) — root cause + fix location; also notes `--testPathPattern` doesn't scope correctly in this repo's test runner
- [Third-party prop string literals](feedback_thirdparty_prop_string_literals.md) — nested bds-* component props (e.g. `mode="search"`) use string literals, not the target's own enum import, matching surrounding file convention
- [Imperative content into non-shadow slot](feedback_imperative_content_into_nonshadow_slot.md) — never set `.textContent` on a `shadow:false` custom element host; ref a plain child node inside its slot instead
- [Fresh worktree missing style-guidelines dist](stencil-worktree-missing-dist-dependency.md) — `stencil build` sass "Can't find stylesheet" errors in a new worktree mean build the `@telesign/boreal-style-guidelines` workspace package first, not a real code bug
- [Slot relocation timing](feedback_slot_relocation_timing.md) — non-shadow slot polyfill relocates light-DOM children before `componentDidLoad`; inspect `this.el` children in `componentWillLoad` instead (bds-button `checkAccessibleName` fix)
- [mock-doc has no :scope selector](stencil-mockdoc-no-scope-selector.md) — `newSpecPage` throws on `:scope`; use `Array.from(el.children).find(...)` for "direct child" checks instead
- [Node relocation breaks on re-render](stencil-node-relocation-breaks-on-rerender.md) — cache a discovered-and-relocated light-DOM node by key; re-querying its original parent after `appendChild` moved it wrongly reports "not found" and Stencil unmounts the moved content (bds-table column footer, EOA-15507 Task 3)
- [JSX Fragment shorthand throws at test runtime](feedback_jsx_fragment_shorthand.md) — never use `<>...</>` in this codebase; import and use `<Fragment>` from `@stencil/core` explicitly (bds-tag/bds-banner precedent, bds-table EOA-15507 Task 5 fix)
- [Radius token lookup](feedback_radius_token_lookup.md) — check `dist/scss/variables/_primitives.scss` for resolved px values; established shared skeleton classes (`.bds-skeleton--rect`) win over a per-node Figma radius re-read
- [Hide real slotted component imperatively](stencil_imperative_hide_slotted_component.md) — no wrapper div to toggle a class on; query the slotted element directly and toggle `style.display` in `componentDidRender` (bds-table paginator skeleton, EOA-15507 Task 5b)
- [vdom key forces element recreation](stencil_vdom_key_forces_element_recreation.md) — give an element a distinct `key` per branch when it alternates between imperative ref-appended content and declarative JSX children, or stale/duplicate DOM content survives the patch (bds-table footer skeleton, EOA-15507 Task 5d)
- [Guard expensive read, not cheap write](feedback_guard_expensive_read_not_cheap_write.md) — split a guarded DOM-sync pass into cached-read + unconditional-write phases, or virtualized/keyed vdom can swap in unstyled elements the guard never revisits (bds-table pin offsets, EOA-15507 Task 8)
- [Stencil dev server stale hashed chunk](stencil-dev-server-hashed-chunk-stale-cache.md) — `pnpm dev:components` can serve a stale content-hashed chunk after incremental rebuild even across full navigations; verify via actual network-fetched URL, restart server if stale, and never navigate to the same URL differing only by `#hash` expecting a real reload
- [Virtual table needs maxHeight to bound DOM](stencil-virtual-table-needs-maxheight-to-bound-dom.md) — without a bounded `.bds-table__wrapper` (via `maxHeight`), the virtualizer's window equals full content height and renders nearly all rows anyway; always set `max-height` when manually verifying bounded `<tr>` counts
- [Pure-reorder verification technique](feedback_pure_reorder_verification_technique.md) — script-driven line-range extraction + assert checks + sorted-diff + before/after real test run, for large no-logic-change class member reorders
- [CLAUDE.md overrides jsdoc-template.md silence on internal JSDoc](feedback_claude_md_no_internal_jsdoc.md) — "JSDoc on exported public API only" means strip ALL `/** */` from `@State()`/`@Element()`/private methods/render helpers, but only when the user directs it explicitly (not a default); apply once confirmed for the task at hand
- [Internal types belong in types/ folder](feedback_internal_types_in_types_folder.md) — even non-exported, implementation-only types (e.g. a virtualizer flat-row-entry union) go in types/IComponent.ts, never declared inline in the .tsx
- [forceUpdate race fix](stencil-forceupdate-race-fix.md) — `forceUpdate(this)` from componentDidLoad/MutationObserver fixes a first-paint light-DOM-read race invisible to newSpecPage (bds-table row-detail, EOA-16000)

- [Scoped stencil dev server invocation](stencil-dev-server-direct-invocation.md) — `with-node.sh bash -c 'cd packages/boreal-web-components && exec node_modules/.bin/stencil build --dev --watch --serve --port N'` avoids the heavy monorepo turbo dev pipeline
- [mock-doc template.content vs childNodes](stencil-mockdoc-template-content-vs-childnodes.md) — `appendChild` on a mock `<template>` writes to `childNodes`, only `innerHTML` populates `.content`; use this to fixture the React/Vue "template children don't populate .content" bug in tests (bds-table row-detail empty-content warning, EOA-16000 follow-up)
- [MutationObserver retry for late template.content](stencil-mutationobserver-retry-for-late-template-content.md) — `applyCellTemplate` silently failed forever when React populates `<template>.content` after first render (no cache, no retry); fixed with a one-shot per-column `MutationObserver` + `forceUpdate` (bds-table cell template, EOA-16000 Task 3 QA fix)
- [componentWillLoad sees 0 children in real browser](stencil-column-discovery-componentdidload-refresh-fix.md) — `this.el.children` is reliably empty in `componentWillLoad` for a lazy-loaded non-shadow component even with static markup; re-run discovery in `componentDidLoad` too, don't rely solely on the later MutationObserver (bds-table column-group, EOA-16000 Task 4, invisible in newSpecPage)
- [table-layout:fixed + colgroup fix](stencil-table-layout-fixed-colgroup.md) — `table-layout: fixed` only reads column widths from a table's first `<tr>`; a multi-row `<thead>` (e.g. `bds-table-column-group`) silently breaks per-`<th>` inline widths unless a `<colgroup>`/`<col>` (exempt from the first-row restriction) is added instead (bds-table, EOA-16000 Task 4)
- [CDN ESM process.env shim](cdn-esm-process-env-shim.md) — raw CDN-imported npm ESM packages referencing `process.env.NODE_ENV` throw `ReferenceError` in bundler-free pages; shim `window.process` with a classic `<script>` before the `<script type="module">` import
- [bds-table th leading-icon layout](bds-table-th-leading-icon-layout.md) — `<th>` isn't a flex container by default; a leading icon before `.th-content` needs a scoped `th:has(> .icon-class) { display: flex; ... }` rule, not a blanket `th { display: flex }` (would break skeleton/group/checkbox/expand `<th>` variants)
- [Keyed `<th>` move blurs focus; key fix can mask a second bug](stencil-keyed-th-move-blurs-focus.md) — `insertBefore`-moving a focused, already-connected DOM node blurs it even as the same object (real Chromium behavior, confirmed via raw-DOM repro), so keyed reorders need an explicit post-render `.focus()` restore; also documents a fix for one reported bug silently masking a second reported bug's exact repro (bds-table column reorder, EOA-16000 Task 5)
